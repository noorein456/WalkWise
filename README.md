
# Walkwise

**Know the path. Walk with confidence.**

Walkwise is an AI-powered pedestrian infrastructure intelligence and accessibility-aware routing platform.

## Vision

To make pedestrian infrastructure visible, understandable, and accessible.

## Initial Geographic Scope

Bengaluru, Karnataka, India.

## Core Objectives

- Map pedestrian infrastructure.
- Identify and analyse footpaths.
- Assess pedestrian accessibility.
- Generate accessibility-aware walking routes.
- Display infrastructure data confidence and freshness.

## Future Scope

- Expansion across India and internationally.
- Mobile camera and GPS-based observations.
- Real-time infrastructure change detection.
- Municipal and institutional integrations.

## Technology Stack

- Python
- React
- FastAPI
- OpenStreetMap
- Leaflet
- PostgreSQL with PostGIS
- Computer Vision
